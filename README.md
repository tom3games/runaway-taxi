# 暴走タクシー

みんなで1台のタクシーを運転して、お客さんを目的地まで届ける協力ゲーム。
担当ごとに押せるボタンも見えるものも違うので、声をかけ合わないと曲がれない。

- 人数: 1〜6人（推奨3〜6人）。1〜2人なら1人が複数の担当を持つ
- 1プレイ: 準備3秒 + 150秒（3幕: 宵の口 → ラッシュアワー → 嵐の深夜）
- 街: 下町・港町・繁華街の3つ（ホストがロビーで選ぶ）
- スマホ縦持ち・横持ち・PC（キーボード）で遊べる。画面は 3D（Three.js）。WebGL が使えない端末では真上から見た 2D に自動で戻る（`?2d` で確かめられる）

## 遊び方

1. 1人が「部屋を作る」→ 招待URLか4文字の参加コードを送る
2. そろったらホストが「スタート」。最初の3秒で自分の担当が出る
3. 光る輪の中で止まるとお客さんが乗る／降りる。150秒で売上3,000円を目指す

遊び方はホームの「遊び方」に絵で出る。開始前の3秒は自分の担当カード（できること・みんなの担当）が出る。

### 担当

| 担当 | できること | 自分だけに見えるもの |
|---|---|---|
| ハンドル | 左・右（押している間だけ曲がる） | なし |
| エンジン | アクセル（1回押すと入りっぱなし、もう1回で切れる）・ブレーキ（押している間だけ。踏むとアクセルも切れる。止まってから押し続けるとバック） | なし |
| ナビ | 掛け声（次を左／次を右／まっすぐ／Uターン／ここで止めて） | 街の全体地図と、行き先・乗り場の場所 |
| 見張り | 掛け声（あぶない／止まれ／行ける） | 夜道の障害物を遠くまで（ほかの人はヘッドライトの届く所だけ） |
| 接客 | なだめる（機嫌+15、8秒に1回）、掛け声（ゆっくり／急いで） | お客さんの注文と機嫌の数字 |

人数ごとの割り振り（だれがどれになるかは毎回ランダム）:

| 人数 | 割り振り |
|---|---|
| 1 | 全部 |
| 2 | ハンドル+見張り / エンジン+ナビ+接客 |
| 3 | ハンドル / エンジン+接客 / ナビ+見張り |
| 4 | ハンドル / エンジン / ナビ / 見張り+接客 |
| 5 | 1人1役 |
| 6 | ハンドル左 / ハンドル右 / エンジン / ナビ / 見張り / 接客 |

途中で抜けた人の担当は、担当が一番少ない人に自動で渡る。

### 連携が要る理由（ルールの芯）

- 速いほどタイヤが滑り、ハンドルが効きにくい。ナビが「次を右」と言っても、エンジンが減速しないと曲がりきれずに建物にぶつかる
- 夜なので、運転する2人にはヘッドライトの届く範囲の障害物（コーン・横切る猫・周回する車）しか見えない。見張りの声が頼り
- 行き先はナビしか知らない。お客さんの注文（急いでいる／スピードが怖い／急に曲がると酔う／途中で寄り道したい／ぶつけると怒る）は接客しか知らない
- 全員に見えるのは、車の動き、ウインカー、どのペダルが踏まれているか、お客さんの顔だけ

### 点数

- 届けると 運賃（距離で決まる）+ チップ（機嫌で星1〜5）+ 注文の上乗せ（間に合った +300、寄り道できた +400）
- 機嫌が0になるとお客さんは怒って降りる（運賃なし）。ぶつける・芝生を走る・目安の時間を過ぎると機嫌が下がる
- ぶつけると車のダメージが増え、100%で廃車（その場で終了・負け）
- 時間切れのとき売上3,000円以上なら勝ち。ランク S 6,000 / A 4,500 / B 3,000 / C それ未満

### だんだん難しくなる（3幕）

| 幕 | いつ | 変わること |
|---|---|---|
| 1 宵の口 | 最初の1/3 | 周回の車が少ない。お客さんは受験生・おばあちゃん・観光客・ちびっこ |
| 2 ラッシュアワー | 1/3 から | 車が増えて少し速くなる。工事の柵が道をふさぐ（車がその場所にいる間は置かない）。酔っぱらい・社長・妊婦さんが乗るようになる |
| 3 嵐の深夜 | 2/3 から | 雨で滑る（横のグリップ 0.45倍・ブレーキ 0.75倍）、ライトが届きにくい、猫がすばしこい。幽霊が乗りやすい（運賃2倍・じわじわ冷える）。届けた運賃は深夜料金で1.3倍 |

信号（街ごとに3〜5か所）は全員の画面に見える。赤で交差点に入ると罰金150円と機嫌−8。周回の車は赤で止まる。

### 街

| 街 | むずかしさ | 特徴 |
|---|---|---|
| 下町 | 1 | 提灯と瓦屋根。行き止まりが4つ。公園は近道だが揺れる |
| 港町 | 2 | 真ん中を川が横切り、橋は2本だけ。川に突っ込むとドボン |
| 繁華街 | 3 | ネオンの路地（幅1マス）が近道。信号と車が多い |

### 記録と称号

結果画面で売上を数え上げ、ランク（S/A/B/C、廃車は×）のメダルとハンコ（営業成功／始末書）を押す。
その回で取った称号（18種。安全運転の鑑・霊感タクシー・壁ドン職人・水陸両用・信号は飾り・廃車請負人など）を最大3つ出し、初めて取ったものには NEW が付く。
街ごとの自己ベスト・取った称号・通算の営業回数と売上は端末（localStorage）に残り、ホームの「記録と称号」で見られる。

### キーボード（PC）

矢印キーかWASD（左右=ハンドル、上=アクセル、下とスペース=ブレーキ。キーボードは押している間だけ効く）、数字キー=掛け声、C=なだめる。自分の担当のキーだけ効く。

## 起動

```
npm install
npm start
```

ブラウザで http://localhost:8103 を開く。ポートを変えるときは `PORT=8080 npm start`。

## テスト

```
npm test                 # ルールの単体テスト + 本物のサーバーにつなぐ統合テスト（50件）
npx playwright install chromium webkit   # 初回だけ
node tools/e2e.mjs       # 実ブラウザで通しプレイ（193項目）
```

`tools/e2e.mjs` は制限時間を18秒に縮めて（環境変数 `TAXI_TIME_LIMIT`。ブラウザからは変えられない）、chromium と webkit それぞれで
作成 → 招待URLで参加 → ホストが街を選ぶ（参加者にも見える）→ 開始 → 担当カード → アクセルのスイッチ・ハンドル・ブレーキ（アクセルが切れる）・掛け声が全員に届く → 3D が描けているか（輝度の分散）→ 第3幕まで走って時間切れ → 余韻の帯 → 結果（ランク・売上の数え上げ・記録が1回だけ残る）→ 再戦 を3人で通す。
ほかに 1人プレイ（キーボード）、`?2d` の 2D 描画、6人（ハンドルが左右に分かれる）を確かめる。
どの画面も 390x844 / 360x640 / 844x390 / 568x320 で上下左右にスクロールせず、見えているボタンが画面内で44px以上か、コンソールエラー0件かも数えている。スクショは `tools/shots/`。

見た目の確認用:

| コマンド | 撮るもの |
|---|---|
| `node tools/shot-ui.mjs` | ホーム・遊び方・記録・ロビー（ホストと参加者）を4サイズで |
| `node tools/shot-game.mjs 1 2 3 4` | 人数ごとに全員の担当の画面（`SIZES='[[360,640]]'` で大きさを変える、`MAP=minato` で街） |
| `node tools/shot-result.mjs` | 結果画面（6人・称号3つ・勝ち／廃車）を4サイズで |
| `node tools/shot-fx.mjs` | 届けた・怒って降りた・猫・信号無視・嵐の深夜・営業終了の演出 |
| `node tools/fps.mjs` | GPU を使う headless Chromium で、スマホ相当（390x844・画素比3）と横持ちの fps を3つの街で。比べる基準に空のページの fps も出す |
| `node tools/live-check.mjs <URL>` | 公開URL（省くと手元）に chromium と webkit の2人でつなぎ、操作・掛け声・3D・OGP・起動エラーの誤表示（20秒）を確かめる |
| `node tools/make-og.mjs` | `public/og.png`（1200x630）を作り直す（3D の画面にロゴと一言） |

## 公開

このフォルダ1つで1サービス。いまは親フォルダの `publish.sh` で、この Mac から Cloudflare の無料トンネル（quick tunnel）経由で出している（Mac が起きている間だけ遊べる。URL はトンネルを開き直すたびに変わる）。

- Render: リポジトリをつなぐと `render.yaml` のとおり Web サービスになる（無料プランは15分アクセスが無いと眠る）
- Fly.io / Cloud Run など: `Dockerfile` をそのまま使う（`PORT` は環境変数で渡る）
- og:image / twitter:image / og:url は、index.html を返すときにサーバーが来たホスト名（`X-Forwarded-Host` / `Host` と `X-Forwarded-Proto`）で絶対URLに書き換える。公開後に SNS のカード確認ツールで画像が出るかは未確認

## 作り

- `lib/game.mjs` ルール。車の物理はサーバーの固定 1/60 秒ステップで進め、画面へは15回/秒で送る
- `public/map.js` 街の地図。サーバーと画面の両方が読む（毎回は送らない）
- `public/game-view.js` 画面（HUD・操作・結果・記録）。届いた位置を約110ms遅らせて間を補間して描く。操作は pointerdown / pointerup で「押した・離した」を送り、押している間（アクセルはスイッチが入っている間）は0.4秒ごとに送り直す。サーバーは1.5秒届かなければ離したとみなす（切断しても押しっぱなしにならない）
- `public/view3d.js` 3D の描画（Three.js r185 を `public/vendor/` に置いて読む。CDN に頼らない。3D は後から読むので、読み込み中はホームやロビーが先に動く）
  - カメラ: 運転・見張り・接客の人はタクシーの後ろ上から前を見る追いかけ視点（車の前＝画面の奥なので、左右のボタンと画面の左右が一致する）。速さで少し引いて画角が広がる。ナビだけの人は北が奥の斜め見下ろしで街全体（建物を低くし、区画の名前を重ねる）
  - 下の操作ボタンに隠れないよう、タクシーが「HUD と操作の間」に来るまで絵を上へずらす（`setViewOffset`）。カメラとタクシーの間の建物は切り取る
  - トゥーンの陰影、立体のちびキャラのお客さんが屋根の窓から顔を出し、機嫌で表情と頭の記号（怒り・汗・ハート・幽霊の火の玉）が変わる。ぶつけると驚いた顔と頭の上を回る星
  - 演出: 届けると紙吹雪とコインとお客さんが跳んで降りる、怒るとお客さんが飛び出す、猫とコーンは跳ね飛ぶ、ダメージ60%から煙・85%から火花とライトのちらつき、廃車は部品とタイヤが飛び散る、時間切れは行灯が「回送」
  - 街ごとの背景: 下町は提灯と五重塔、港町は川と橋・観覧車・クレーン・回る灯台、繁華街はネオン看板。信号機は本当の色で点く。工事の柵は幕2から立ち上がる。第3幕は雨・稲光（画面にも雨すじ）
  - 重さ対策: 画素比の上限（画質 高2 / 中1.5 / 低1）、影は月の1灯で高画質のときだけ、建物は InstancedMesh。fps が42を切ると画質を1段下げる（スマホは中から始める）
- `public/sound.js` 効果音・エンジン音（速さで高さが変わる）・雨音・街ごとの BGM（幕が進むと速くなる）。Web Audio で鳴らす（音声ファイルなし）。ゲーム中の右上で消せる
- 秘密（行き先・注文・遠くの障害物）は `view(playerId)` でその担当にだけ入れる。単体テストで確かめている
- 1人あたりの送信は1回1.5KB未満（テストで確認）
